# The Next Line Is Yours

Entry for make.fun bounty "Write the best poem about agency"
(https://make.fun/bounty/agency-poem-01).

`main.py` (Python 3.13, standard library only) writes one fixed poem
about agency — choosing, acting, and writing your own next line — to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

Deterministic: no network, no randomness, no clock. Two runs write
identical bytes. The poem is 1–1,000 characters of UTF-8 text.
